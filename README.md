# Color Spin · 混色达人

单文件网页小游戏：点选颜色，按住 START 旋转圆盘，松手后混色与标准色比对打分。

## 安装

无需构建、无依赖：直接用浏览器打开 `index.html`，或起静态服务：

```sh
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 玩法示例

1. 点选两侧色块（点已选色块可取消，可随时改选）
2. 按住 START 旋转圆盘，松手停止自动评分（≥85 分过关）
3. 同一关 3 次未过关会公布正确组合，可继续转动测试，点「→」下一轮

进度保存在浏览器 localStorage。含 12 色经典 / 24 色进阶两种难度，共 100 关。
